# college-admission-system
The College Admission &amp; Course Allocation System is a Python-based application that uses a MySQL database to automate the student admission process. It allocates courses to students based on their marks, preferences, and seat availability, ensuring a fair and merit-based system.
The system also provides features like multi-round allocation, cutoff calculation, PDF admission confirmation, and CSV export for reporting. Overall, it simplifies the admission process and can be further enhanced with a web interface and advanced security features.
